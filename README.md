# Stereodrome

Stereodrome is a desktop music player for Subsonic compatible music servers.

Key aspects:
- Cross-platform, built using Tauri and Svelte 5 + DaisyUI
- Sleek interface inspred by classic iTunes player, just modernized a bit
- Local metadata storage: Stereodrome syncs metadata into local storage for faster interface and song searching
- Local SQLite for song metadata storage, Tantivy for full-text search
- Rodio as audio backend
